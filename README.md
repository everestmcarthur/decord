# decord — canvas branch

Auto-generated by `main`'s `update (hourly)` workflow (`src/update/tasks/colors.ts`). Do not edit manually.

## Layout

Colors are split per Discord release channel: `alpha/`, `beta/`, `stable/`. Each channel has the same contents:

- `raw.json` — Discord's raw colors (`tokens/colors/generated/raw-color-definitions.tsx`)
- `semantic.json` — Semantic colors (full, with `raw` + `opacity` per theme)
- `semantic_simple.json` — Simplified semantic (`{semantic: {theme: hex}}`)
- `version.txt`

`version.txt` is written only after a successful run. A placeholder `0` signals "never processed" (forces the first run).

## `raw` / `semantic` for themers

- `raw.json`: `{ "BLACK_100": "#...", ... }` ~200 keys
- `semantic.json`: `{ "BACKGROUND_PRIMARY": { "dark": ["#...", {raw:"BLACK_500", opacity:1}], "light": [...] }, ... }`
- `semantic_simple.json`: `{ "BACKGROUND_PRIMARY": { "dark": "#...", "light": "#..." } }`

Use `semantic_simple.json` for quick theming, `semantic.json` + `raw.json` to resolve `raw` references.
